## 📌 О проекте
Проект представляет собой Fullstack-систему, объединяющую физические датчики и веб-интерфейс для обеспечения комфорта и безопасности в доме. Система позволяет следить за микроклиматом (уровень CO2, температура) и визуально контролировать питомцев в режиме реального времени.

### 🌟 Ключевые возможности
*   **Real-time Мониторинг:** Сбор данных с датчиков (температура, влажность, CO2).
*   **Аналитика:** Интерактивные графики динамики показателей (библиотека Recharts).
*   **Видеонаблюдение:** Доступ к видеопотоку через модуль ESP32-CAM.
*   **Smart-уведомления:** Оповещения при выходе показателей за критические границы.
*   **Безопасность:** Защищенная авторизация пользователей на базе JWT.

## 🛠 Технологический стек

### **Hardware (Железо)**
*   **Микроконтроллеры:** Wemos D1 mini (ESP8266), ESP32-CAM.
*   **Датчики:** MH-Z19B (CO2), DHT22 (Температура и влажность).

### **Backend**
*   **Runtime:** Node.js (TypeScript)
*   **Framework:** Express
*   **ORM:** Prisma
*   **Database:** PostgreSQL / SQLite
*   **Auth:** JSON Web Tokens (JWT)

### **Frontend**
*   **Library:** React + TypeScript
*   **Styling:** Tailwind CSS
*   **Charts:** Recharts

## 🎯 Целевая аудитория
1. **Владельцы животных:** Контроль состояния питомца в течение дня.
2. **Эко-осознанные пользователи:** Мониторинг качества воздуха в офисе или дома.
3. **Заботливые родственники:** Присмотр за детьми или пожилыми людьми.
4. **Инженеры умных домов:** Интеграция в существующие системы автоматизации.

## 🚀 Ожидаемый результат
Итогом является **Dashboard (веб-приложение)**, которое в реальном времени отображает состояние аппаратных модулей, хранит историю измерений и предоставляет доступ к видеотрансляции.
